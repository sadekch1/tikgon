# TikGon 🎬

تطبيق أندرويد بواجهة تشبه TikTok (خلاصة تمرير عمودية) يعمل فوق واتساب:

- يربط رقم واتسابك مرة واحدة داخل التطبيق (رمز ربط — Baileys، والجلسة محفوظة في التطبيق).
- تراقب **محادثة واحدة** تختارها (محادثة البوت).
- عندما يضخّ البوت فيديوهات فيها (بأمر `.redgif`)، ينزّلها TikGon تلقائياً في الخلفية ويعرضها خلاصةً تمرّرها لأعلى/لأسفل.
- **استقبال فقط**: التطبيق لا يرسل أي رسالة واتساب، ولا يشغّل أي فيديو من تلقاء نفسه أبداً.

> ⚠️ Baileys مكتبة غير رسمية وقد يحظر واتساب الحساب؛ استخدم رقماً لا تخسر منه.

## البناء (GitHub Actions)

1. أنشئ مستودعاً جديداً على GitHub وادفع إليه محتوى هذا المجلد كاملاً (`android/` و`.github/`).
2. يبدأ Workflow باسم **Build TikGon (Android)** تلقائياً عند الدفع (أو شغّله يدوياً من تبويب Actions).
3. عند نجاحه: **Actions ← آخر تشغيل ← Artifacts** ← نزّل **TikGon-Android** وفيه `TikGon-android.apk`.
4. (اختياري) لصفحة تنزيل دائمة: `git tag v1.0 && git push origin v1.0` فتُرفق الـAPK في **Releases**.

## أول تشغيل

1. ثبّت الـAPK (اسمح بالتثبيت من مصدر غير معروف) واسمح بالإشعارات.
2. **ربط الرقم**: أدخل رقمك مع رمز الدولة، ثم في واتساب: الأجهزة المرتبطة ← ربط جهاز ← «الربط برقم الهاتف بدلاً من ذلك» ← أدخل الرمز الظاهر في التطبيق.
3. **اختيار المحادثة**: اختر محادثة البوت من القائمة (أو أدخل رقم البوت يدوياً). TikGon سيراقب هذه المحادثة فقط.
4. ابدأ خلاصة من واتساب: أرسل للبوت `.redgif <كلمات البحث>` ثم اختر الجودة مرة واحدة (HD/SD).

## طريقة العمل

| الخطوة | ماذا يحدث |
|---|---|
| `.redgif asian ass` | البوت يبحث ويضخّ الفيديوهات في الشات واحداً تلو الآخر |
| وصول الفيديوهات | TikGon ينزّلها في الخلفية حتى لو التطبيق مغلق |
| بوابة البداية | العرض يُفتح بعد اكتمال **10 فيديوهات** منزّلة — بعدها لا انتظار |
| المشاهدة | افتح التطبيق واضغط ▶ بنفسك. التمرير ينقلك للتالي |
| الاقتراب من الحافة | عند بقاء 3 فيديوهات غير مشاهَدة تظهر بطاقة «استراحة»؛ أثناء الاستراحة تُجهَّز دفعة جديدة وتصلك إشارة **صامتة** عند جاهزيتها |
| الحذف التلقائي | كل فيديو تشاهده يُحذف من الهاتف بعد **10 دقائق** — إلا ما تحفظه بالقلب ❤️ |
| `.stopredgif` | إيقاف ضخّ البوت من واتساب |

## أزرار العرض (في المشغّل وفي الإعدادات)

- **⛶ ملء الشاشة**: يخفي أشرطة النظام وواجهة التطبيق.
- **🔄 التدوير**: يقفل العرض أفقياً. و«التدوير التلقائي» (مفعّل افتراضياً) يدوّر الفيديوهات الأفقية فقط.
- تضبط الوضع مرة واحدة — **يبقى محفوظاً** ويُطبَّق على كل فيديو وكل جلسة حتى تغيّره.

## أزرار كل فيديو

- **❤️ حفظ**: يبقى نهائياً في صفحة «أنا» ولا يُحذف أبداً.
- **⬇️ تنزيل**: نسخة في معرض الهاتف (`Movies/TikGon`).
- **↗️ مشاركة**: مشاركة الملف بأي تطبيق.

## البنية

| المجلد | المحتوى |
|---|---|
| `android/` | تطبيق أندرويد (Kotlin + Compose + محرك Node مضمّن يعمل بـBaileys) |
| `android/nodejs-project/` | محرك الواتساب (يُجمَّع بـesbuild داخل الـAPK أثناء البناء) |
| `.github/workflows/build.yml` | بناء الـAPK |

نفس هيكل مشروع WA Hub: محرك Node يعمل في عملية مستقلة، يتواصل مع الواجهة عبر HTTP محلي، وخدمة مقدمة تُبقيه حياً للتنزيل في الخلفية.
